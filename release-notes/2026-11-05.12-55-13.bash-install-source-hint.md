`toolr self completion install bash` now prints `source <installed path>` to add to your bash startup file when it can't find the bash-completion package, which is the only thing that loads the install directory. Without bash-completion, or with it installed but not enabled, the script used to be installed but never loaded. Interactive shells read `~/.bashrc`; login shells, such as the ones macOS Terminal opens, read `~/.bash_profile`. `toolr --quiet` drops the hint.
