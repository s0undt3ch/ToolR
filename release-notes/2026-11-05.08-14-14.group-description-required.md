**Breaking:** the manifest build now fails when no `command_group` call for a group passes a description or docstring, listing every module that declares it, and when one call passes `docstring=` together with `description=` or `long_description=`. Title-only calls such as `command_group("ci", "CI")` still work as long as one declaration describes the group, in any module and in any order. Python already refused both shapes when the declaring module imported, but a group declared only in a module no command imports could build and run before. `CommandsTester` reports both with the same text.
