**Breaking:** the manifest build now fails when no `command_group` call for a group passes a description or docstring (an empty one counts as none), listing every module that declares it, and when one call passes `docstring=` together with `description=` or `long_description=`. Title-only calls such as `command_group("ci", "CI")` still work as long as one declaration describes the group, in any module and in any order. Before, `command_group` raised for these only when the call created the group as its module imported, so a group created in a module no command imports could build and run; such a tree now fails to build. `CommandsTester` reports both with the same text. A plugin that adds commands to a host's group must describe that group in its own declaration, or its `toolr self build-manifest` fails.
