`toolr project init` now prints `toolr: trusted <repo>` when it records trust in the repository, as `toolr project trust` does. `--quiet` keeps it silent.

Outside a project, an unknown command now ends with `toolr: no toolr project found above <directory> (looked for tools/pyproject.toml)`, so a wrong working directory no longer looks like a typo.

On Windows, `ctx.repo_root` and the command's working directory are now plain paths (`C:\repo`), not the verbatim `\\?\C:\repo` form, so `git -C` and relative-path code behave.
