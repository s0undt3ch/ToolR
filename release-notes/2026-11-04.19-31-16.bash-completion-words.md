Bash completion now works for file names and choice values containing `:` or `=` (bash split them into separate words, so they completed nothing or repeated the typed prefix), and without the bash-completion package, which the script no longer needs. It now needs bash 4.4 or newer: on an older bash, sourcing the script prints one warning and registers nothing. This is new, but completion never worked on bash 3.2, which failed on every Tab. Re-run `toolr self completion install bash --force`, or re-source the script, to pick it up.

The warning prints only in an interactive shell, so a bashrc sourced by scripts or `bash -c` stays quiet.
