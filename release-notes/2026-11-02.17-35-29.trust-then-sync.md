`toolr project trust` now syncs the tools venv after trusting the repository, so a fresh clone needs one step before its commands run. On a terminal it asks first (`Sync it now? [y/N]`); declining keeps the trust and points you at `toolr project venv sync`. Running a command in an untrusted repository works the same way: answer `y` to the trust prompt and, if the venv is missing, out of date or broken, toolr offers to sync it and then runs the command. The sync prompt replaces the uv install prompt for that sync, so you see at most two prompts. With `--quiet` or no terminal toolr doesn't ask and doesn't sync unless `TOOLR_AUTO_INSTALL_UV=1` is set. Pass `--no-sync` to only record the trust. If a sync you agreed to fails, the trust is kept and the command exits non-zero.
