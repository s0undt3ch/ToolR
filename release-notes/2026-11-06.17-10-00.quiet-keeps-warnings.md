**Breaking:** `toolr --quiet` (and `-q`) no longer hides warnings. A command run with `-q` now prints, on stderr, the warnings that it used to drop: a skipped or shadowed plugin, build warnings from a rebuilt manifest, the `toolr-py` version mismatch and the failed `meta.json` touch. Scripts that run `toolr -q <command>` against a project with such a problem will start to see that output on every run. `--quiet` still drops success lines and advice, never errors, refusals or warnings, and the root `-q` help now says so.
