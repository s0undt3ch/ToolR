**Breaking:** every `TOOLR_*` boolean variable now reads `1`, `true` or `yes` (any case) as on, and everything else as off. `TOOLR_NO_CACHE_HINT` used to mean "set to anything", so `TOOLR_NO_CACHE_HINT=0` silenced the cache hint; it now leaves it on. `TOOLR_TRUST_ALL` and `TOOLR_AUTO_INSTALL_UV` used to need exactly `1` and now also take `true` and `yes`. A `bool` option bound with `arg(env=)` accepts `1`, `true`, `yes`, `0`, `false` and `no`, where it took only `true` and `false`. The same spellings now apply to every `bool` value read from text: a positional, a list or tuple element, `--opt=VALUE` and an `arg(env=)` variable. Values are trimmed and matched case-insensitively. `--help` no longer lists `[possible values: true, false]` for those options.
