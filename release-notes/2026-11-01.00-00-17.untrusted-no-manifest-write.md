In an untrusted repository toolr neither reads nor writes `tools/.toolr-manifest.json`, parses nothing
under `tools/` and doesn't look inside `tools/.venv`, so inspecting an unfamiliar checkout leaves it
untouched. Once you trust a repository, toolr uses an in-tree `tools/.venv` only if it built that venv
itself. Any other in-tree venv, including one an older toolr built, is removed and rebuilt on first use.
