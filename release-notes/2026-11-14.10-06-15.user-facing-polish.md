Every `toolr project` and `toolr self` command now reports a missing project with the same message, `toolr: no toolr project found above <dir>`. The stale-manifest warning now shows the parse error in the tools file (with its line and column), and any control characters in it are escaped.

A command that raises now prints a traceback that starts at your own code, without the toolr runner frames above it. `toolr -d` keeps the full traceback.
