Sync the tools venv (no-op unless tools/pyproject.toml, uv.lock, uv.toml or .python-version changed
since the last sync; an in-tree venv toolr didn't build is removed and rebuilt)

Usage: toolr project venv sync [OPTIONS]

Options:
      --if-project
          Exit 0, silently, when there is nothing to sync: not in a toolr project, no readable venv
          location, or uv absent and not installable without asking (for shell and editor hooks)
  -f, --force
          Re-run uv sync even when none of those files changed (e.g. after changing UV_*
          environment variables or user-level uv config)
  -U, --upgrade
          Re-resolve every package (passes --upgrade to uv). Combine with -P to also force specific
          packages.
  -P, --upgrade-package <PACKAGE>
          Re-resolve a single package; pass repeatedly for multiple. Each <PACKAGE> must be declared
          in tools/pyproject.toml.
  -h, --help
          Print help
