Sync the tools venv (no-op unless tools/pyproject.toml, uv.lock or .python-version changed since the
last sync)

Usage: toolr project venv sync [OPTIONS]

Options:
  -f, --force
          Re-run uv sync even when none of those files changed (e.g. after changing uv environment
          settings)
  -q, --quiet
          Silent on success and on benign unattended-mode exits (no toolr/uv output)
  -U, --upgrade
          Re-resolve every package (passes --upgrade to uv). Combine with -P to also force specific
          packages.
  -P, --upgrade-package <PACKAGE>
          Re-resolve a single package; pass repeatedly for multiple. Each <PACKAGE> must be declared
          in tools/pyproject.toml.
  -h, --help
          Print help
